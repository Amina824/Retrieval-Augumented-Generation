                     ====Text Splitting ====

Text splitting is breaking large chunks of text into smaller manageable pieces that an LLM can handle. if we give larger text to LLM the quality of output will be poor.

==== WHY Text Splitting? ====

1-Overcoming model limitation
Every LLM has context length limit meaning the length of tokens/text the llm can handles as input as once. If we dont perform text splitting, the model will not perform well
For Example:
An LLM has limit of 50k tokens, if u have pdf that has tokens more than 50k , you cant directly give it to LLM. That's where text splitting helps
